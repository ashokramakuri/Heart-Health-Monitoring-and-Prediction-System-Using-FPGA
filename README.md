# Heart-Health-Monitoring-and-Prediction-System-Using-FPGA
FPGA-based ECG monitoring using Zybo Board, Vivado, and Vitis.

Domain: FPGA & Embedded Systems

Technologies: FPGA, Verilog HDL, RTL Design, Machine Learning, PhysioNet, MIT-BIH ECG Database
This project involves real-time ECG signal acquisition using gel electrodes, followed by signal processing and analysis on an FPGA using Verilog HDL and RTL design. Machine learning models were trained using the PhysioNet and MIT-BIH ECG datasets to predict potential heart diseases. The system continuously monitors heart activity and detects abnormalities, enabling reliable real-time cardiovascular monitoring.
